# Bundled fonts

IBM Plex Sans (400/500/600) and IBM Plex Mono (400/500), Latin and Latin
Extended subsets (Turkish included), as distributed unmodified by
[Fontsource](https://fontsource.org) 5.x. Copyright IBM Corp., licensed under
the SIL Open Font License 1.1 (see the `OFL-*.txt` files). Served locally by
Streamlit static file serving; no network access is needed at runtime.
